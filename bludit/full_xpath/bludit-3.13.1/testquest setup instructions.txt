REQUIREMENTS  
- Java JDK 17 or higher  
- IntelliJ IDEA 2023.2.6 (Community Edition) or higher  

INSTALLING TESTQUEST  
1. Open the test project with IntelliJ  
2. From the interface, select File > Settings > Plugin > "gear icon" > Install Plugin from Disk  
3. Select and upload the zip 'testquest.zip'  
4. Restart IntelliJ  
5. Upon reopening, the Gamify menu should be visible at the top, with a sub-option Test Quest  

USING TESTQUEST  
1. Open the test project with IntelliJ, then select Gamify > Test Quest  
2. When prompted by the "Gamification Mode" window, select the option "Locator-based"  
3. When prompted by the "Saved Data Found" window, select "Yes"  
4. In the main "TestQuest" window, select the option "Targeted" in the lower section called "Daily Assignment Mode"  
5. Scrolling through the "Dailies" panel of the main "TestQuest" window, clicking the various "Show" buttons will list the locators to be modified  
6. Every modification applied to a locator must be validated by running tests. A modification to a locator is considered valid if the locator executes correctly  

CONSTRAINTS ON LOCATORS AND TEST METHODS  
1. Always assign locator declarations to variables (e.g. WebElement variable = driver.findElement(By.xpath("//div")))  
2. Do not modify the names of variables associated with locators  
3. Do not remove existing locators  
4. Do not add new locators  
5. Locators must be exclusively within methods annotated with @Test  
6. Tests must not contain any conditional logic (e.g. NO if/switch/for)  
7. Locator values must not reference parameters (e.g. NO WebElement e = driver.findElement(By.xpath("//div["+i+"]")))
